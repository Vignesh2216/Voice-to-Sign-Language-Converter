Voice to Indian Sign Language

Convert spoken words into expressive Indian Sign Language animation and video. This project helps make voice input accessible to users who rely on ISL by generating sign language output from speech.

  • Record or type speech text
  • Convert text to ISL animation
  • Preview generated video output
  • Easy mobile and desktop access
Go to Generation Page

How it works

Speak or enter a phrase on the generation page, then generate a sign language video. The server sends the text to the speech recognition module and returns an animated ISL output for playback.

Why this matters

Supporting Indian Sign Language helps bridge communication gaps for users who are deaf or hard of hearing, and makes voice-driven applications more inclusive.
